## 📌 1. Project Overview & Requirements Mapping

This project is engineered to fulfill and exceed the requirements of **Elevvo Internship Task 5**:
- **Build a Responsive Landing Page for a Tech Product (SaaS)**: Production-grade marketing landing page designed for a next-generation enterprise cloud orchestration platform.
- **Key Sections Required**:
  1. **Hero Section**: High-converting headline, dual CTA buttons, trust badges, live real-time KPI counters, and interactive 3-tab dashboard preview.
  2. **Features Grid**: Modern Bento Grid layout featuring 6 architectural capabilities (Autonomous AI Agents, Sub-12ms Edge Mesh, Zero-Trust Cryptography, Real-time Log Streamer, Visual CI/CD Pipelines, and FinOps Cost Optimizer).
  3. **Social Proof & Testimonials**: Industry-filtered customer stories (FinTech, Autonomous AI, Enterprise Cloud) with verified customer avatars and measurable metric badges.
  4. **Pricing Matrix**: 3 transparent tiers with interactive Monthly / Annual billing switch (-25% discount) and glowing "Most Popular" card border.
  5. **Call-to-Action (CTA)**: High-conversion lead capture banner with work email regex validation and interactive toast confirmation.
- **Bonus Requirement**:
  - **Full Dark / Light Mode Toggle**: Seamless, flash-free, high-contrast theme switching adhering to **`FRONTEND_ARCHITECTURE_BLUEPRINT.md`** and **`PRODUCTION_STANDARDS_PLAYBOOK.md`** with blocking `<script>` execution in `<head>` and persistent state in `localStorage`.
- **Architectural Excellence & Playbook Compliance ("تطابق كامل مع معايير الإنتاج العالمية")**:
  - **The Mobile Trio Layout (Playbook Section 3.1 & Blueprint Section 9)**: Sticky Header (`z-50`), Mobile Bottom Taskbar (`z-40` with `pb-safe`), Slide-out Drawer (`z-[60]`), and Portaled Modal (`z-[99999]`).
  - **Icon Badge Formula (Playbook Section 2.1 & Blueprint Section 4)**: Standardized `h-11 w-11` SVG badge containers with zero raw emoji icons in production components.
  - **Maximum Contrast Hard Rule (Blueprint Section 2)**: Guaranteed high contrast across all states — pure `#fafafa` on dark zinc, `#09090b` on light zinc, zero washed-out mid-gray text.
  - **Scrollbar Stability & Autofill Guard (Blueprint Section 9, 11)**: `scrollbar-gutter: stable` preventing layout shifts, and `-webkit-autofill` theme overrides.
  - **Shimmer-Wave & Micro-Interactions (Blueprint Section 5, 12)**: Kinetic tactile feedback (`active:scale-95`), floating animations, and subtle shimmer wave highlights.
  - **Interactive ROI & Cloud Savings Calculator**: Real-time dual sliders for engineering team size and cloud spend calculating instant dollar savings and reclaimed developer hours.
  - **Bilingual Arabic & English Support (RTL/LTR)**: Complete instant localized switching between English and Arabic with localized typography (`Lexend` & `IBM Plex Sans Arabic`).
  - **Interactive Product Demo Video Modal**: Glassmorphic walkthrough modal with backdrop blur, scroll locking, and Escape key listener.
  - **Interactive Micro-Widgets**: Live log streaming terminal simulator, Anycast latency comparison slider, and 256-bit encryption toggle.
  - **Verified Floating Social Dock**: Direct channels for **Sayed Nada** (GitHub, LinkedIn, WhatsApp, Email).

## 🛠️ 2. Technologies & Architectural Standards

- **Core**: Semantic HTML5, Vanilla JavaScript (Modular ES6+ Object-Oriented Architecture), Modern CSS3.
- **Design Tokens**: Standardized Slate/Zinc palette, Cyan-500 (`#06b6d4`) & Teal-600 (`#0d9488`) accent gradients.
- **Typography**: Google Fonts (`Lexend`, `IBM Plex Sans Arabic`, `Plus Jakarta Sans`, `Tajawal`, `JetBrains Mono`).
- **Icons**: Handcrafted scalable SVG vectors following the Lucide specification.
- **Accessibility & SEO**: WCAG AA compliant contrast, single `<h1>`, dynamic `aria-expanded`, semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
- **Zero-Friction Runtime**: Standalone architecture tested and fully functional on both `http://` servers and local `file:///` paths.

## 🚀 3. How to Run Locally

### Option 1: Direct File Launch
Double-click `index.html` in Windows Explorer to view directly in any browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server
```bash
cd "projects/05-tech-saas-landing-page"
python -m http.server 5175
```
Then open [http://localhost:5175/index.html](http://localhost:5175/index.html).
